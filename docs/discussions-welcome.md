# Discussions 欢迎帖（开启 Discussions 后发布）

## 标题

`👋 欢迎来到 Personal Workbench 讨论区`

## 正文

```markdown
欢迎来到 **个人工作台 APP（Personal Workbench）** 的讨论区 👋

这是一个开源的个人效率中心 Android 应用：笔记、待办、日程、目标、工程项目、文件与统计报表在同一个工作台内无缝流转，Offline-First，本地 Room 数据库为唯一数据源。

### 这里可以聊什么

| 分类 | 适合的话题 |
| --- | --- |
| ❓ 问答 (Q&A) | 使用方法、配置问题、闪退排查 |
| 💡 想法和建议 (Ideas) | 功能提案、交互改进、你认为值得做的事 |
| 📣 公告 (Announcements) | 版本发布说明、重要变更 |
| 🛠️ 开发交流 (Development) | 架构讨论、踩坑分享、PR 协作 |

### 提问前请先看

1. **README** —— 功能范围、技术栈、31 个版本的更新日志都在这里，多数疑问已有答案
2. **CONTRIBUTING.md** —— 本地构建命令、代码约定、数据库迁移注意事项
3. **已存在的 Issue** —— 先搜一下，可能已经有人问过并解决

### 反馈 Bug 请走 Issue

Bug 报告请用仓库的 **Issue 模板**（`Bug 报告` / `功能建议`），表单会引导你附上设备信息、系统版本和复现步骤——这些信息对定位问题至关重要。讨论区适合开放式讨论，不适合结构化的缺陷上报。

### 参与贡献

欢迎提 PR，动手前请先读 [CONTRIBUTING.md](CONTRIBUTING.md)。本项目采用 [MIT 许可证](LICENSE)，你贡献的内容将同样以 MIT 发布。

期待你的想法 💬
```

---

## 发布方式

1. 仓库 **Settings → General → Features → Discussions** 打开开关（该操作 GitHub 未开放 API，只能网页手动开启）
2. 复制上面的标题与正文，发布为第一帖（建议分类选 **📣 公告 Announcements**）
3. 顺带检查默认分类是否齐全，缺 `❓ 问答` / `💡 想法和建议` 可在 Discussions 页右上角新建
