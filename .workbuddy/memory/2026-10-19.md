## PersonalWorkbench V1.5.6 追加 — 交付命名规范（用户约定）
- 用户要求后续文件命名按 `<应用名>-<版本号>-release` 格式（样例 `SudokuMaster-1.6.0-release`）。
- `app/build.gradle.kts` 加 `applicationVariants.configureEach` → `outputs.forEach { (it as BaseVariantOutputImpl).outputFileName = "PersonalWorkbench-${versionName}-${buildType}.apk" }`；release/debug 均自动命名，随 versionName 更新。
- 坑（AGP 8.2.2 + Gradle Kotlin DSL）：`configureEach { variant -> }` 传参式 lambda 报类型不匹配，须用接收者风格 `configureEach { val variant = this; ... }`；`outputs` 是 List（不是 DomainObjectCollection），不能用 `.all`；`BaseVariantOutput.outputFileName` setter 在 AGP 8 已移除，须转型内部类 `com.android.build.gradle.internal.api.BaseVariantOutputImpl` 才能赋值。
- 验证：assembleRelease/assembleDebug 均成功，输出 `PersonalWorkbench-1.5.6-release.apk` / `PersonalWorkbench-1.5.6-debug.apk`；release v2+v3 签名通过，SHA-256 `076b6ab7b172bf3207b05e7771e76be48974d22dffd057ca442719894aa263e2`（内容与更名前的 1.5.6 完全一致，仅文件名变化）。
